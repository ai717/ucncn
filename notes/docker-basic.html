Docker 基础命令清单与轻量级环境部署实战

📅 发布日期：2026-09-15 🏷️ 标签：Docker / 容器化 / 运维小抄 ⏱️ 预计阅读：7 分钟

在本地开发或轻量级服务器上，容器化可以极大减少“在我的机器上能跑，在服务器上就报错”的环境污染问题。本文提炼一份日常最常用的 Docker 命令速查手册。

一、容器生命周期管理

# 查看当前正在运行的容器
docker ps

# 查看所有容器（包括已停止的）
docker ps -a

# 后台启动一个 Nginx 容器，并将主机 80 端口映射到容器 80 端口
docker run -d --name my-web -p 80:80 -v /www:/usr/share/nginx/html:ro nginx:alpine

# 停止 / 启动 / 重启容器
docker stop my-web
docker start my-web
docker restart my-web

# 强制停止并删除容器
docker rm -f my-web

二、进入容器调试与排错

当容器启动异常或需要检查内部配置时：

# 实时跟踪容器的标准输出日志（最后 100 行）
docker logs -f --tail 100 my-web

# 以交互式终端进入运行中的容器
docker exec -it my-web /bin/sh

三、磁盘空间清理（高频运维必备）

构建或拉取多次镜像后，服务器磁盘极易被中间层镜像（dangling images）占满：

# 查看 Docker 占用的磁盘总体分布
docker system df

# 一键安全清理：未使用的容器、网络、以及虚悬无标签镜像
docker system prune -f

# 彻底清理所有未被任何容器引用的镜像（慎用，适合大扫除）
docker image prune -a --force

四、轻量化部署建议

  • 优先选用 Alpine 基础镜像：例如 python:3.11-alpine 或 node:20-alpine，体积通常只有 50MB~100MB，极大节省云主机带宽和存储。
  • 目录外挂 Volume 做好备份：所有业务持久化数据（日志、静态文件、SQLite 数据库）必须通过 -v 挂载到宿主机，实现容器随时销毁重建而数据无损。
