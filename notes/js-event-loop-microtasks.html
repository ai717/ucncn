深入浅出 JavaScript 事件循环机制：宏任务与微任务执行时序

📅 发布日期：2026-04-16 🏷️ 标签：前端开发 / 实用备忘 ⏱️ 预计阅读：5 分钟

一、执行时序核心法则

每次事件循环轮次中：首先执行同步主代码（第一个宏任务） → 清空当前微任务队列（Promise.then、queueMicrotask） → 触发页面渲染微批次 → 取出下一个宏任务（setTimeout/setInterval）。
