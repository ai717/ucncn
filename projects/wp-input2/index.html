WordPress 实用插件 支持 Yoast SEO 智能容错引擎

WP Structured Draft Importer 📝

配合大语言模型写作，将 AI 生成的结构化 JSON 数据一键全量转化为标准的 WordPress 草稿，原生同步 SEO 字段，彻底告别格式错乱。

📦 立即下载插件安装包 (ZIP) 版本：v1.0.3 · 体积：43 KB · 兼容 WordPress 5.8+ 及 PHP 7.4~8.2+

💡 为什么需要这款插件？

在利用 AI（ChatGPT、Claude、通义千问、豆包、DeepSeek 等）辅助产出专业博客、SEO 资讯或评测文章时，传统做法是将正文一段段复制粘贴到 WordPress 古腾堡或经典编辑器中。这一过程存在严重痛点：

  • 格式反复折腾：从 Markdown 转为 HTML 时容易丢失标题层级（H2/H3）、对比表格错位、代码块高亮失效；
  • 元数据重复填写：固定链接 Slug、分类目录、多标签、文章摘要往往需要反复人工手动输入；
  • SEO 字段割裂：如果使用 Yoast SEO，必须手动逐篇填写焦点关键词、SEO 标题与 Meta Description，耗时耗力。

WP Structured Draft Importer 通过一份纯净的标准 JSON 彻底解决了所有问题。大模型一次性输出 JSON，在后台粘贴即可秒级生成排版完美的待审草稿！

✨ 五大核心特性

🚀
全要素一键入库
单次导入完整覆盖标题、富文本正文（纯 HTML）、英文固定链接 Slug、分类、标签数组与摘要。
🎯
Yoast SEO 深度集成
原生解析 yoast_seo 对象，自动映射焦点关键词、SEO 自定义标题与元描述，无需再手动复制。
🛡️
严谨的分类安全保护
绝不自动创建未知的乱七八糟新分类。仅精确匹配站点已有的分类名称或 ID，保持分类架构严谨干净。
🧠
启发式智能容错引擎
自动剥离 Markdown 代码块包裹，自动修复 HTML 属性内未转义双引号与换行控制字符，避免 JSON 解析报错。

📋 标准 JSON 输入规范示例

{
  "title": "2026年家用扫地机器人选购指南与避坑指南",
  "slug": "robot-vacuum-cleaner-buying-guide-2026",
  "category": "数码家电",
  "tags": ["扫地机器人", "智能家居", "避坑指南", "家电评测"],
  "excerpt": "本文梳理 2026 年主流激光导航、双线激光避障及全自动上下水扫地机的实测表现与选购要点。",
  "content": "<h2>一、核心避坑要点</h2><p>选购扫地机首看避障与吸力协同...</p>",
  "yoast_seo": {
    "focus_keyword": "扫地机器人选购指南",
    "seo_title": "2026家用扫地机器人深度选购与避坑指南 - 极客家电",
    "meta_description": "全面对比各档位主流扫地机清洁效果与自动化维护成本，助你少花冤枉钱。"
  }
}

🚀 快速安装使用方法

  1. 点击上方下载按钮获取 wp-structured-draft-importer-v1.0.3.zip；
  2. 登录你的 WordPress 网站后台，进入 「插件」 → 「安装插件」 → 「上传插件」；
  3. 选择刚下载的 ZIP 文件并点击“现在安装”，安装完毕后点击“启用插件”；
  4. 在 WordPress 左侧主菜单中即可看到「草稿导入器」，将 AI 生成的 JSON 粘贴进去，点击“解析预览”或“直接创建草稿”即可！

🔒 纯净安全承诺

本插件完全遵循 WordPress 官方编码规范，所有数据输入均经过严格的 sanitize_text_field、wp_kses_post 与 wp_verify_nonce 过滤校验，仅具备文章创建权限的管理员才可操作，轻巧纯粹，零外网冗余请求。
