豆瓣电影基因 (Movie DNA)

解构个人多年全量观影数据，绘制属于你独一无二的审美基因雷达、导演偏好网络与小众片单预测模型。

🎬 立即进入电影基因实验室 →

项目简介与设计理念

在流媒体与海量电影信息爆炸的时代，通用的热门排行榜和算法推流往往难以契合资深影迷或个性化受众的审美。“豆瓣电影基因”是基于个人多年真实的观影记录与短评数据，通过纯前端数据清洗与可视化图表技术构建的一套个人化影视审美决策模型。

核心功能模块规划

📊
五维审美雷达
从叙事厚度、视听美学、哲学深度、娱乐快感、冷门探索度五个维度精准刻画个人审美倾向。
🕸️
导演与影人关系网
基于打分频次与高分标记，拓扑聚类出你偏爱的作者电影流派与高粘性黄金班底。
🎯
专属避坑与选片预测
通过题材红黑榜算法过滤，在你看一部新片之前，科学预测你的真实喜好概率。
🔒
本地离线数据解析
所有 CSV / 文本格式的观影数据均在浏览器本地安全解析，不上传任何云端服务器，保障纯净隐私。

技术架构与部署规范

  • 宿主环境：作为「菜鸟笔记」的独立子工程，部署于 ucncn.cn/projects/movie-dna/ 子路径下。
  • 技术栈规划：纯原生 JavaScript + ECharts / D3.js 数据可视化库，保持极低依赖与毫秒级加载速度。
  • 合规保障：遵循个人备案非营利性规范，不设立用户注册与支付，作为开放的个人技术展示专区。

💡 当前状态：模块接口设计中
